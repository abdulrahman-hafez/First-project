# Expense Tracker

A simple web application for managing personal expenses.

## Technologies
- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express.js
- PostgreSQL

## Features
- Add expenses
- View all expenses
- Filter by category
- Edit expenses
- Delete expenses
- View total expenses
- View total amount
- View highest expense

## Categories
- Food
- Transport
- Entertainment
- Bills
- Other
 

## API
- GET `/api/expenses`
- GET `/api/expenses/:id`
- POST `/api/expenses`
- PUT `/api/expenses/:id`
- DELETE `/api/expenses/:id`


## Run
1. Run `npm install` inside the backend folder.
2. Configure the PostgreSQL database.
3. Start the server using `npm start`.
4. Open the frontend using Live Server.
